This repository contains all custom-made MATLAB scripts used for generating the figures in the article.

In subfolders named '7-res', there are .mat files containing the fluorophore step sizes and molecule counts identified at each pixel location of the TIRF images.

To download the raw TIRF images underlying the figures, we refer to	https://doi.org/10.25740/sp776gx3909.
